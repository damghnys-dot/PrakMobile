# Welcome to My Project!

Halo semuanya! Selamat datang di repositori aplikasi **TRIO PlayStation**. 
Ini adalah project pembuatan aplikasi mobile **Rental PS (PS4 & PS5)** untuk praktikum Pemrograman Mobile yang dikerjakan secara bersama-sama oleh:

- **King Althof** (`@thvvsn`)
- **Ayam Bagti** (`@Bagti330`)
- **Ayam Adam** (`@damghnys`)

Aplikasi ini dibuat menggunakan **React Native (Expo)** untuk memudahkan pelanggan dalam melihat katalog paket sewa harian maupun mingguan, melihat informasi fasilitas tempat rental yang buka 24 jam di Malang, serta melakukan booking unit PlayStation secara langsung dan praktis.
